When recreating a page from Figma, build and verify ONE section at a time, then stop and inform the user before moving to the next — never implement the full page in one shot.

**Why:** User (2026-10-07, new homepage rebuild) wants to review each section as it lands and redirect early.

**How to apply:** Per section: pull Figma data → implement → verify in browser against the Figma screenshot → report with a screenshot → wait for go-ahead. Related: [[feedback-explain-before-implementing]].
